# 联网检索查新（Step 5）

> 本文件用于按技术主题查找现有技术。著录检索（发明人/申请人清单等）**不在本包**；整仓时另走检索技能，**禁止**把检索技能当成本包查新引擎。

## 必做时机

生成交底书全文**之前或生成过程中**必须执行；检索结论写入第一章 **1.1 现有技术** 及与本案的**区别论述**。

## 分析要求

对检索到的、与方案**高度相关**的现有专利或公开文献逐项概括：

## D1 锁定与区别特征 Fk（写 1.1 前必做）

检索完成后**不要**直接铺开写 1.1。先把「跟谁比、差在哪」写进内部稿 **`查新与区别定位_{YYYYMMDDHHmmss}.md`**（用户索要时可给）。这是审查三步法的**成文骨架**，不是交底表格的法定栏：主比对钉一篇出发点，禁止把多篇揉成一团。成文纪律见 **`invention/disclosure_builder.md` §7.10**。

本包查新默认是一词一页 + 摘要，**不是**已读全文。定位稿须标明**证据级别**（摘要 / 公开文本未通读 / 领域较远），**禁止**把摘要级判断写成已核实全文。

### 1. 选出 D1（最接近的现有技术）

**D1 = 技术方案最接近的一篇**，作为逐特征主表的出发点；**不是**命中列表第一条，**不是**公开日最新的一篇。

- `EPUB_HITS_JSON` **没有公开日字段，脚本也不做相关度排序**；数组顺序只是页面顺序 + 去重 + 多词合并。**禁止**按数组下标或公开日认定「最接近」。先按上文 **3b.6** 对摘要打分，**从精排池**里选 D1。
- 选定优先级：① 精排分最高且解决同一技术问题、手段/模块相似；② `abstract` 与本案方案重叠面最大；③ 覆盖本案拟保护要点最多；④ 同族或同申请人多篇取**代表篇**，其余作背景。
- 须写一句**选定理由**（为什么是它，而不是另一篇）。两篇几乎一样近：仍先定一篇为 D1，另一篇标 **D2**，不要平均。
- 其余条目在 1.1 作技术背景。**不要**五篇各露半截再拼成「本发明」——那是马赛克对比。

### 2. 逐特征比对表（产出 Fk 编号）

**主表只对 D1。** 按**技术维度**逐行比对，给每条实质区别一个编号 **F1、F2…**（全案唯一、口径唯一）。**编号在表里完成定义**：单独成「编号」列，「本案怎么做」写满构造/机制，**禁止**最后一列只写「是（F1）」把「是否区别」和「叫什么」叠在一格。能进这张表的都是区别，不必再开「是否区别」列。有 D2 补行时「对比文献」列标 `D2（补行，组合风险）`，无则该行不要。

**定位稿**可继续密写 Fk。**交底正文**的出场纪律见 **`invention/disclosure_builder.md` §7.10「Fk 出场」**：表 + 表后一览定义一次；1.2 / 二 / 四说人话；三 / 六禁止用 Fk 当主语；5.1 用 Fk 作条目标签并复述全文。不要把列名叫成「本专利权要」（交底书不是权利要求书）。

| 编号 | 对比点 | 对比文献 | D1 / 对比文献怎么做 | 本案怎么做 |
|------|--------|----------|---------------------|------------|
| F1 | 节点资源刻画 | D1 | 单一 CPU 负载阈值 | 对节点 CPU/内存/IO 做窗口平滑聚合，得到资源画像 |
| F2 | 重排时机 | D1 | 每次派发前均重排 | 间隔阈值与分数变化阈值双条件才触发重排 |
| F3 | 重排范围 | D1 | 全队列 | 重排只作用于队列窗口子集 |
| F2 | 窗口平滑（组合风险） | D2（补行，组合风险） | 公开指数滑动平均 | 本案窗口平滑与间隔/分数双阈值触发联用 |

表后写 **特征一览**（后文只用这些中文简称，F 号最多句末括注）：

- F1 资源画像：对节点 CPU/内存/IO 做窗口平滑聚合
- F2 双阈值触发：间隔与分数变化双条件才重排
- F3 窗口子集：重排只作用于队列窗口而非全队列

**D2 补行不是第二套 D1**：仅当「D1 没有、本案有、且 D2 公开了相近手段、审查时可能拿来组合」时才加行。不要把 D2 的全部特征铺进主表，也不要对五篇做并列逐特征。无组合风险则不要 D2 行。「本案怎么做」禁止只写「与 F1、F3 联用」——用中文复述联用的是哪段构造。

维度须是**技术维度**；**禁止**把「申请人 / 申请年份 / 是否授权 / 文献篇数」当比对维度。上表按本案替换（实用新型比部件与连接关系；外观比造型、图案、色彩要点，可不用 Fk 编号）。

定位稿文首用一行写清：**门禁状态**（过 / 带疑点过 / 不过）+ **证据级别** + D1（及可选 D2）公开号。不过且未钉住出发点时写 **D1=未钉住**，不要填一篇不相干的公开号。

### 3. 门禁（三态；三态都进 Step 6）

轻量查新锁「最接近」证据有限。门禁管的是**创造性骨架写到哪一档**，**不**拦截交底成文。**不要**为了填表去指定一篇不相干的当 D1，也**不要**在写得出具体区别时仅仅因为「没读全文」就降成「不过」。

| 状态 | 何时 | 下一步 |
|------|------|--------|
| **过** | D1 与本案同一问题、手段/模块重叠清楚；至少一条 Fk 能落到 D1 的**具体**不足 | 进 Step 6；预览点名 D1 与 Fk |
| **带疑点过** | 仍能点名一篇出发点并写出至少一条指向该篇（或 D2）的实质区别，但证据不足或出发点不稳——例如仅摘要、两篇几乎一样近、命中偏远领域、开创性而最近的一篇仍较远 | 进 Step 6；定位稿与预览**必须**写出不确定处；交底 1.1 不得装成已读全文。实用新型结构区别能指到具体文献时**优先用本态** |
| **不过** | 写不出任何一条能落到**具体对比文件**不足上的实质区别——开创性、检索只有远领域噪声、或两组发明点其实该拆案 | **仍进** Step 6 / 7。创造性论述**降级**（见下）；预览开头写明未钉住最接近对比文件 |

**「不过」仍成文，降级规则（硬项）**：

- **禁止**把不相干命中标成 D1；**禁止**编造对比文件或链接；**禁止**空喊「本质区别」「创新性强」。
- 1.1 检索结果如实当背景（远领域噪声就当背景，不逐特征）。**不**点名最接近的一篇，写清「本次未钉住可作最接近现有技术的对比文件」。
- 区别对「材料里的现有做法 / 本领域常规」写，Fk 仍在 1.1 一览与 5.1 编号，并标明**未经对比文件钉死**；1.2 / 二 / 四仍说人话，不要靠 F 号当索引。
- 1.2 指到上述现有做法的具体不足，不要写「现有技术普遍存在不足」。
- 该拆案：先写一篇，5.1 写明无共同必要特征，预览建议拆；**不要**停在 Step 5.5。

另：

- 某条 Fk 的手段词在本轮检索里**从未被检索词覆盖** → 就该 Fk 的手段词补一轮检索（规则同上文第 4 点），再判断它是否站得住（可因此从「不过」升到「带疑点过」）。
- 某条 Fk 与 D1 高度重合、只剩参数取值差异 → 如实记录，交由第五章按 **§7.10** 归入**附加/优选特征**，**不要**硬写成独立创新点。

过 / 带疑点过：1.2 每条缺点应能在表里找到对应的 D1 或 D2 一侧。不过：1.2 对材料或常规做法，不虚构 D1 侧。
